# Conversão local BLIVRE

Com dependências instaladas, execute com um executor TypeScript, por exemplo `npx tsx scripts/convert-blivre.ts <translation_id-UUID> > blivre.json`. O executor `tsx` não está configurado no projeto; instale-o separadamente no ambiente antes de executar, sem alterar o projeto. O diretório USFM pode ser informado como segundo argumento. O arquivo JSON é gerado localmente; nenhum banco ou serviço é acessado. O UUID deve corresponder a uma tradução previamente criada. Os registros de versículo são sempre não publicados; as regras de licença da migration continuam aplicáveis.

O JSON contém livros, capítulos e versículos relacionados por UUID, atribuição, data de conversão, fonte, checksum do pacote registrado e SHA-256 calculado de cada USFM. O checksum registrado refere-se ao ZIP original e **não é verificado** nesta conversão, pois o ZIP não está presente. Os hashes dos arquivos extraídos identificam a entrada atual, mas não comprovam sua autenticidade. Conserve o registro de licença e os metadados junto aos dados importados.

O campo `content` conserva os marcadores USFM e as notas dentro de cada versículo, removendo apenas os espaços externos da linha; requer renderização USFM para leitura. Títulos de salmos (`\\d`) e metadados fora dos versículos permanecem somente nos arquivos de origem, que não são modificados. A conversão rejeita estruturas não suportadas, livros ausentes, numeração repetida e intervalos de versículos; não comprova por si só a completude editorial nem a integridade do ZIP original. Teste: `npm test -- tests/importers/blivre.test.ts`.
